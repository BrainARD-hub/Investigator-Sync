# Privacy Policy for Investigator Sync

Last Updated: May 2026

## Overview

Investigator Sync is a browser extension that automatically synchronizes a curated collection of OSINT and cybersecurity bookmarks from a public GitHub repository.

## Data Collection

Investigator Sync does not collect, store, transmit, or share any personal information.

The extension does not:
- Track browsing activity
- Monitor search history
- Collect bookmarks outside the folder it manages
- Use analytics or telemetry
- Sell or share user data

## Network Requests

The extension makes one network request to download the public `tools.json` file from:

https://raw.githubusercontent.com/BrainARD-hub/Investigator-Sync/main/tools.json

This file contains only bookmark categories and URLs.

## Local Storage

The extension stores:
- Installed version number
- Last update timestamp

This information is saved locally in the browser and is never transmitted externally.

## Third-Party Services

The extension relies on:
- GitHub (to host the public bookmark configuration)

## Changes to This Policy

This privacy policy may be updated as the extension evolves.
