# Investigator Sync

Investigator Sync is a browser extension that automatically synchronizes a curated collection of OSINT and cybersecurity bookmarks from a public GitHub repository.

## Features

- Automatic bookmark synchronization
- Organized categories and subcategories
- Works with Chrome and Firefox
- Updates delivered through GitHub
- Community-driven tool collection

## Installation

### Firefox

Download the latest release from:
https://github.com/BrainARD-hub/Investigator-Sync/releases

Or install from Mozilla Add-ons (coming soon).

### Chrome

Download the latest release from:
https://github.com/BrainARD-hub/Investigator-Sync/releases

Or install from the Chrome Web Store (coming soon).
