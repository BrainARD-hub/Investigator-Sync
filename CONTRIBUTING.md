# Contributing to Investigator Sync

Thank you for helping improve Investigator Sync.

## Ways to Contribute

You can contribute by:
- Suggesting new OSINT or cybersecurity tools
- Reporting broken links
- Improving documentation
- Fixing bugs
- Submitting pull requests

## Tool Submission Requirements

Suggested tools should:
- Be legitimate and trustworthy
- Provide value to investigators
- Be accessible online
- Not host malware or deceptive content
- Comply with applicable laws and ethical standards

## tools.json Format

Each bookmark entry uses the following format:

```json
{
  "title": "Tool Name",
  "url": "https://example.com"
}

## Category Format

{
  "name": "Category Name",
  "bookmarks": [],
  "subcategories": []
}
